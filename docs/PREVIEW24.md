# Preview 24

The private ISO importer preserves the alpha channel in XP's 32-bit bitmaps.
The Start flag no longer acquires an opaque black matte from the BMP decoder.
Explorer imports native Shell32 toolbar frames (16/24 pixels), including back,
forward, parent folder, search, folder tree and view selection. The toolbar uses
24-pixel icons and grey disabled navigation buttons. Microsoft artwork remains
in the user's private import only; no originals are distributed in this package.

The pinned XP Explorer and default folder handler open the folder tree directly,
including when an Explorer process is already running. The desktop My Computer
shortcut continues to open the tasks view. When Explorer is selected as the
default file manager, its pin replaces Nemo's pin. Nemo remains installed and
available through the application menu/search and Explorer's Extras menu.
The original pin list remains part of the reversible installation backup.
