# Preview 23

The global Cinnamon/GNOME event-sound switches are normal user preferences.
Updates retain their current values. Uninstall and explicit snapshot restore
restore the original/selected values, with actual before-values in the durable
transaction journal. File changes and other settings still block conflicting
operations. Original installation backups are never replaced by this repair.

Private XP ISO import now maps personal folders, Control Panel categories,
common settings, media types and session actions. Explorer bitmap resource 143
provides the Start flag when present. Small icons use native resource sizes.
The tested XP Professional x64 medium yields 97 icon names and 26 WAV files;
other XP editions may contain fewer optional resources. Existing imports must
be imported again to receive the expanded mappings. Application brands and
Linux-only features retain suitable fallback icons. Microsoft resources are
never included in the public DEB or source archive.

All 26 WAV files are retained privately. Linux event mappings use only the
applicable subset. No equivalent is invented for Internet Explorer's old
pop-up/information-bar events. Global mute is independent of file integrity.

Validation: synthetic PE/ISO parsing, invalid resource bounds, global-mute
update/uninstall/restore and transaction-failure tests; VM results are recorded
separately from automated tests.
