# After the first GitHub preview

## Optional desktop helper

Karl Klammer / Clippy is planned for a later update, after the initial GitHub repository. It is not included in Preview 38.

- A movable helper with speech bubbles, contextual help and an off switch.
- Useful offline explanations for installation, backups, Explorer and shortcuts.
- A bundled original mascot; optional private import of a supported character file or archive. An entire Office installation should not be necessary.
- Microsoft character artwork remains separate from the public package. Community implementation licences do not automatically license the original graphics.
- Optional OpenAI API integration with credentials in the operating-system keyring.
- Evaluate the official Sign in with ChatGPT flow for open-source clients, subject to eligibility and supported functionality.
- No automatic upload of files or screenshots; clearly show the context being shared.

This is a roadmap, not a promise of compatibility or a completed integration. Rover remains the optional privately imported Explorer search companion. Publishing this roadmap does not introduce a Microsoft, Linux Mint or OpenAI affiliation.
